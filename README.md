# 工程光学仿真实验平台 · 第 1–3 章

基于 HTML5 Canvas 与原生 JavaScript 的中文交互式光学实验。使用参数控制、实时光路、数值读数和动画，帮助理解几何光学的基本规律。

本仓库公开第 1、2、3 章，共 24 个实验主题。页面与资源均保存在仓库中，无需前端框架、npm 依赖或在线 CDN。

## 实验内容

| 章节 | 主题数 | 内容 |
| --- | --- | --- |
| 第 1 章：几何光学基本定律与成像概念 | 8 | 直线传播、反射、折射与全反射、费马原理、马吕斯–杜潘定理、完善成像、球面近轴与实际光路 |
| 第 2 章：理想光学系统 | 10 | 焦点、主点、节点、基点基面、焦距与折射率、物像共轭、放大率、系统组合、厚透镜与正切计算 |
| 第 3 章：平面与平面系统 | 6 | 平面镜转动、微小位移测角、平行平板、折射棱镜、双光楔及包含多种棱镜的 3D 模型库 |

各实验支持即时调参、播放/暂停、恢复默认值和 Canvas 截图下载。具体可调参数和操作提示以相应页面为准。

## 快速开始

需要 Python 3 和支持 Canvas 的现代浏览器。

```bash
git clone https://github.com/libwszu/engineering-optics-lab-demo.git
cd engineering-optics-lab-demo
python -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/>，从首页进入实验。停止服务时按 `Ctrl+C`。也可直接打开 `index.html`；使用本地 HTTP 服务更便于检查资源加载。

## 部署

本项目是纯静态网站，无构建步骤。可将仓库根目录交给静态服务器，也可在 GitHub 仓库的 **Settings → Pages** 中选择 `main` 分支、`/ (root)` 目录进行托管。

## 教材与模型说明

章节内容参考蔡怀宇《工程光学复习指导与习题解答》（第 2 版）。教材名称和页码用于说明学习背景，仓库不分发教材 PDF。

模型用于教学演示，部分采用近轴、理想系统或示意化近似，理解结果时应结合页面中的公式前提。共享模型的维护和测试由项目维护者在独立开发环境中完成。

本项目尚未指定开源许可证；公开可见性不代表已授予额外的使用或再分发许可。
